# TokBrain

TokBrain 是一个 Windows 优先的本地知识库工具。用户主动粘贴自己有权访问和处理的抖音公开作品分享文本，TokBrain 使用固定版本 F2 对单个作品做低频预检。只有平台明确返回作者允许下载时，用户确认后才会下载完整媒体并进入关键帧、OCR、语音转写、总结和 RAG 流水线；禁止下载或权限状态未知时，不下载完整视频、不抽帧，只尝试字幕、独立音频，失败则退化为标题、简介和作者等基础信息。

> 作者允许下载只控制媒体处理范围，不代表自动取得转载、商用或向第三方公开内容的授权。F2 单作品解析仍可能触发平台限流、验证或其他风控。

## 安全边界

- 每批最多提取 10 条有效链接，每个上海自然日最多发起 150 次 F2 单作品解析。
- 固定启动 3 个异步 worker；短链跳转、F2 单作品解析和公开媒体访问共用一个全局锁，网络并发始终为 1。
- 每条链接结束后随机等待 4–8 秒。网络超时或 5xx 最多重试一次，重试前随机等待 15–30 秒。
- 403、429 或风险验证会立即终止当前批次的后续访问，并持久化熔断 30 分钟。
- 短链逐跳检查 HTTPS、域名、端口、DNS 与私网地址，重定向最多 5 次。
- 预检成功会立即保存到待确认区。预检阶段不下载媒体、不调用 AI、不可检索。
- 下载权限采用失败关闭策略：只有 `allow_download=true` 或等价的明确允许信号才进入完整媒体流程；禁止、缺失或无法识别的信号均进入“字幕/音频/基础信息”流程。
- 中断只在安全边界停止；已成功结果保留，未开始条目会标记为已取消。
- 应用重启不会自动继续任何平台访问或遗留处理任务。
- 不提供账号登录、专用浏览器、CDP、收藏夹扫描或启动采集。F2 可选 Cookie 只用于用户主动发起的单作品解析，并由 Windows DPAPI 加密保存。

## 本地补件

F2 没有返回可处理媒体时，可以上传本地源文件继续：

- 视频：单个 MP4、MOV、MKV 或 WebM，最大 1 GB。
- 图文：1–12 个 JPEG、PNG 或 WebP；单张最大 30 MB，总计最大 180 MB。
- 服务端忽略原文件名，使用 UUID 路径，并通过文件魔数、Pillow 和 ffprobe 验证实际内容。
- 本地源文件会保留到作品被永久删除，便于重新处理。

## 启动

首次安装依赖后，可直接双击根目录的 `启动.cmd`；需要重启时双击 `重启.cmd`。
服务就绪后会使用系统默认浏览器打开 `http://127.0.0.1:3000`。如果网页没有自动打开，
请手动复制该地址到浏览器。启动日志位于 `data/logs/`。

需要 Python 3.12、Node.js 22+ 和 ffmpeg（含 ffprobe）。

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pip install --no-deps --target .vendor -r requirements-f2.txt
cd frontend
npm install
cd ..
.\start.ps1
```

后端默认监听 `127.0.0.1:8000`，前端默认监听 `127.0.0.1:3000`。应用数据位于 `data/`。

## v4 API

- `POST /api/import-batches`：提交多行分享文本。
- `GET /api/import-batches/{batch_id}`：读取进度、worker 状态、逐条结果、额度和熔断状态。
- `POST /api/import-batches/{batch_id}/cancel`：安全中断预检。
- `POST /api/import-batches/{batch_id}/confirm`：确认选中结果并创建入库任务。
- `POST /api/import-items/{item_id}/assets`：上传本地补件。
- `GET /api/jobs`、`GET /api/jobs/{id}`、`POST /api/jobs/{id}/cancel`：统一任务管理。

知识库、聊天、总结、导出、设置和费用接口继续保留。

## 数据升级

首次启动 v4 时会先在 `data/backups/` 创建带时间戳的 SQLite 备份，再事务化转换数据：

- 历史作品、知识块、总结、关键帧、用量和静态分组会保留。
- 多账号状态合并为单一本地空间，状态优先级为 `in_library > issues > pending > archived`。
- 缺少有效知识块的旧入库项转入“处理异常”。
- 新增固定“手动导入”分组。
- 旧敏感残留无法清理时，导入功能会保持禁用并给出处理提示。
